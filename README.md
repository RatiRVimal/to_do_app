
# To-Do App

A simple and intuitive to-do application built with [Streamlit](https://streamlit.io/).

## Features

- ✅ Add new tasks
- ✏️ Edit existing tasks
- ❌ Delete tasks
- 📋 View all tasks
- 💾 Persistent storage

## Installation

```bash
pip install streamlit
```

## Usage

Run the application:

```bash
streamlit run main.py
```

Open your browser and navigate to `http://localhost:8501`
